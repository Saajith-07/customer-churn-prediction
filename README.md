# Customer Churn Prediction System

## Overview
This project predicts customer churn using machine learning techniques. It helps businesses identify customers likely to leave.

## Tech Stack
- Python
- Pandas, NumPy
- Scikit-learn

## Features
- Data preprocessing
- Feature encoding
- Model training
- Prediction

## Results
- Achieved good accuracy using Random Forest Classifier

## How to Run
1. Install dependencies:
   pip install pandas scikit-learn

2. Run:
   python churn_model.py
